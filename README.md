 # 🌱 Smart Agriculture – AI-Based Crop Recommendation System

An AI-powered crop recommendation system that suggests the most suitable crop based on soil nutrients and environmental conditions using Machine Learning.

## 📌 Project Overview

Smart Agriculture is a Machine Learning-based application designed to help farmers make better crop selection decisions.

The system analyzes important soil and weather parameters and recommends a suitable crop based on the trained Machine Learning model.

## 🚀 Features

- 🌾 AI-based crop recommendation
- 🧪 Soil nutrient analysis
- 🌡️ Weather condition analysis
- 📊 User-friendly Stream lit interface
- 🤖 Machine Learning prediction
- 🔄 Instant crop recommendation

## 🛠️ Technologies Used

- Python
- Stream lit
- Pandas
- Scikit-learn
- Machine Learning
- Pickle

## 📥 Input Parameters

The system uses the following parameters:

- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- pH
- Rainfall

## ⚙️ How It Works

1. User enters soil and weather parameters.
2. The trained Machine Learning model processes the input.
3. The system predicts the most suitable crop.
4. The recommended crop is displayed through the Stream lit interface.
